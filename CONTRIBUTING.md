# Mitmachen bei OpenEOS / Contributing to OpenEOS

Danke, dass du OpenEOS verbessern willst! / Thanks for helping to improve OpenEOS!

## Contributor License Agreement (CLA)

Bevor wir einen Pull Request übernehmen können, musst du einmal unserem Contributor License Agreement (CLA) zustimmen. Du behältst dein Urheberrecht; du erlaubst LUXCODE, deinen Beitrag unter der AGPL und auch unter anderen Lizenzen zu nutzen. Der CLA Assistant meldet sich automatisch in deinem ersten Pull Request – ein Klick auf den Link, mit GitHub anmelden, zustimmen, fertig. Die Zustimmung gilt für alle Repositories von OpenEOS-Project.

Before we can merge a pull request, you need to accept our Contributor License Agreement (CLA) once. You keep your copyright; you allow LUXCODE to use your contribution under the AGPL and under other licences. CLA Assistant comments on your first pull request automatically – follow the link, sign in with GitHub, agree, done. Your acceptance covers all repositories of OpenEOS-Project.

## Pull Requests

- Pull Requests bitte gegen den Branch `dev` stellen (openeos-printer-agent: `main`). / Please target the `dev` branch (openeos-printer-agent: `main`).
- Commit-Nachrichten auf Englisch. / Commit messages in English.
- Sicherheitslücken bitte nicht als Issue melden, sondern wie in SECURITY.md beschrieben. / Please report security issues as described in SECURITY.md, not as public issues.
