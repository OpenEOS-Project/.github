# .github

Organization-wide community health files for [OpenEOS-Project](https://github.com/OpenEOS-Project). GitHub uses them for every repository that does not provide its own version.

- [SECURITY.md](SECURITY.md) – how to report a vulnerability (German/English)
- [SECURITY_PLAYBOOK.md](SECURITY_PLAYBOOK.md) – internal procedure for handling reports and Cyber Resilience Act notifications (German)
